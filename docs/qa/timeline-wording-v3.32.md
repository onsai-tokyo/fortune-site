# 時系列の文面確認・修正（v3.32）

## 方針

「あなた」は本人の人生の流れとして読み、「ふたり」は選択した相手との関係として読む。占術の点数・閾値・判定条件・時期の選択は変更しない。

原仕様は `docs/timeline-v3/IMPLEMENTATION.md` と `backend/src/lib/report/timelineV3/signals.ts` を参照した。原仕様では本人の時系列にも相手の登録情報が判定材料として入る。今回はその入力・判定を残し、出力文面の主語と前提を修正した。

## 修正

- 本人の時系列の段階説明から「出会って○年」「関係が始まって○年」を除き、元の進展／見直し／両方／穏やかの判定に対応する本人視点の文章へ変更。
- 本人の「二人の将来」などを「自分の将来」などへ調整。恋愛・人間関係のテーマは残す。
- 本人の段階タグを「関わり方を考える時期」に変更。タグの判定条件は維持。
- 過去の可能性を「ことがあったかもしれません」と表現。約2年半の周期は「入りました」とし、まだ終わっていない期間を「続きました」としない。
- ふたりの年表参照は「ご自身の年表にある結婚」などと明記。本人の結婚年を選択した相手との結婚年と決めつけない。
- 元恋人・片思いの穏やかな年の短いタイトルを、関係区分に対応した既存のタイトル群から選択。
- 保存済みカードの再生成に向けて版番号を v3.32 に更新。

## 確認範囲

7つの出生サンプル、本人の関係ステータスと相手区分の組み合わせ、ふたりの7区分・出会い年2パターンから474件を生成。修正前後の判定オブジェクトは474件すべて一致。本人257件の要約では「出会って」「関係が始まって」「二人」の混入は0件。

これは全生年月日の網羅検証ではない。性格・静的な相性・自由記述AI鑑定は今回の変更対象外。

ビルド確認: `npm run build --prefix backend`。
