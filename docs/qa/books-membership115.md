# 鑑定書作成の月額会員確認（ビルド115）

対象はユーザーが指定した「鑑定書をつくる」。AI相談チャットの無料枠は変更しない。

残り通数だけで作成できていた仕様を、月額会員資格と利用枠の両方が必要な仕様へ変更。

- 未会員が「鑑定する」を押すと、相談内容を保持して月額会員の確認・購入画面を表示。
- 購入確認後に会員資格と利用枠をサーバーへ再照会。元の相談を一度だけ作成する。
- キャンセル・購入失敗・会員確認失敗・残高不足・アカウント切替では自動作成しない。
- POST /api/books は既存の受付を照合した後、新規注文について会員資格を必須化。既存注文の確認・本棚の閲覧は会員資格に関係なく維持。
- 購入済み／審査用の利用枠は削除しないが、残っていても新規作成には会員資格が必要。追加の単品枠購入は会員向け。
- 既存の作成受付番号を使う再試行・二重課金防止は維持。

検証: backend の鑑定書・会員ゲートHTTPテスト15件、iOSの購入配送・購入後再開テスト12件成功。
実Apple購入から鑑定完了までの通し確認はTestFlight実機で行う必要がある。
