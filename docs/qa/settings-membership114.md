# 設定の月額購入ポップアップ（ビルド114）

ユーザー報告: 設定の「月額会員になる」を押しても料金説明のポップアップ自体が開かない。

設定画面全体のsheetとアカウント削除ダイアログの表示先を分け、月額会員ボタンが専用のsheet状態を持つ構造へ変更。装飾枠はヒットテスト対象から外し、ラベルの横幅をボタン全体に拡張した。購入処理と権限検証は変更していない。

確認: iOS 26.5 SimulatorのDebug表示確認モード（--membership114-preview）で、実際のSettingsMembershipButtonからPaywallSheetが開き、閉じてもう一度開くことを確認。対象を絞った購入配送・タブ回帰テスト11件成功。

限界: 報告されたiOS 18実機での元の不具合は再現できていない。表示確認モードはログイン済み設定画面全体のテストではなく、購入ボタンと料金sheetの検証。Appleの決済完了はTestFlight実機で別途確認する。
