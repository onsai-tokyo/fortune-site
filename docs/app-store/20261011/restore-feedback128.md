# 購入復元の表示修正（ビルド128）

## 確認できた問題

設定の「購入を復元」は、実行中の表示も会員状態のまま成功した場合の完了表示もなかった。ユーザーの「押しても何も動かない」はこの実装で起こり得る。実機のボタン入力やApple同期自体が失敗していたかは未確認。

## 変更

- 実行中のスピナー、Appleへの確認／サーバーへの反映の進捗を表示。
- 二重操作を抑止し、アカウント切替時に復元表示をクリア。
- 復元完了時に会員状態と、取得できた場合は解約後の利用期限を表示。
- Appleの有効なサブスクリプションが見つからずサーバーが会員とする場合は、その差を明示。
- 同期エラーを成功として表示しない。
- 料金画面にも復元結果を表示。

## 検証

- Debugビルド成功。
- 購入配送・期限表示など21件成功。
- 会員状態の同期失敗、同時実行、最新状態の反映、アカウント切替後の古い応答排除の4件成功。
- backend TypeScriptビルド成功（backend変更なし）。

## 未解決

ユーザーのApple管理画面は10月11日終了、アプリは10月12日15:06まで利用可能と表示。アプリの解約期限表示はStoreKitの署名検証済みTransaction.expirationDate由来であり、DBだけの表示ではない。元のApple画面と端末の最新トランザクションを照合できていないため、どちらが正しいかは未確定。DBの強制失効やアカウント削除は実行していない。128での実機復元結果を確認して切り分ける。

この修正は、購入復元のフィードバックを改善するものであり、新規購入可能になることや、期限不一致の解消を保証しない。App Reviewへの再提出は行わない。
