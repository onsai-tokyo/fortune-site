# 時系列鑑定 v3 ロジックまとめ（v2.25 / timeline-v3.31）

時系列の判定は「人生の時期」と「占術」の2層でできています。

- **人生の時期**：年齢・交際の年数・結婚の年数。出来事の時期を最もよく当てる要素です。
- **占術**：四柱推命とインド占星術。その年の意味と書き分けを決めます。

**何が当たりを左右するか**：著名人442人の検証（VALIDATION.md §1k）では、占術の目印を約230個組み合わせても、年齢だけで当てるのと同じ精度でした。そこで v2.16 から、年齢と関係の年数を判定の土台にしました。占術は、その年の性格（何が、どう動くか）と文章の個別化に使います。

## 1. 一人分の時系列

### 1-1. 入力

| 入力 | 使い道 | ないとき |
| --- | --- | --- |
| 生年月日 | 年齢、四柱推命の命式（すべての土台） | 作れない |
| 出生時刻 | インド占星術（R1、木星・土星の通過）、10年の流れの切り替わる月 | インド占星術は使わない。10年の流れは正午で近似 |
| 性別 | パートナーの星（女性は官星、男性は財星）、R1の惑星 | R1・R3を使わない |
| 出生地 | 時差、インドのラグナ | 東京として計算 |
| 今の状況（交際中・相手なし・既婚） | 婚期、年代の文の書き分け | 中立の文 |
| 働き方 | 仕事の言葉 | 「活動」 |
| 登録した相手と出会った年・その相手の種類（任意、v2.19・v2.23） | 交際の窓の起点（年表がなくても使う）。片思い・復縁希望・元恋人・夫婦でも使い、文面を種類に合わせる | 年表の交際の始まり、なければ年齢の窓 |
| 年表（任意） | 交際・結婚の年数による時期の窓、出来事の言い直し | 年齢の窓だけ |
| 登録した相手の生年月日（任意、v2.24） | 窓の年の一文を二人の運気で選ぶ | 本人の運気で選ぶ |

### 1-2. 人生の時期の窓（v2.16）
その年が次のどれかに当たると「時期の窓」とします。上から順に決め、年表はその年より前の出来事だけを使います。

| 窓 | 条件 | 意味 |
| --- | --- | --- |
| 結婚 | 年表の結婚（その後に離婚・別れがないもの）から3〜7年がたつ年 | 関係を見直しやすい時期（離婚の中央は結婚6年目、6割が1〜7年目） |
| 交際 | 年表の交際の始まり（出会い・復縁を含む一続き）、または登録した相手と出会った年（交際中のとき。v2.23 から相手の種類〈片思い・復縁希望・元恋人・夫婦〉があれば状況に関係なく）から1〜3年がたつ年 | 関係の形が決まりやすい時期（交際から結婚までの中央は3年） |
| 年代 | それ以外で26〜34歳 | 出会いや関係の節目が重なりやすい年代（結婚の中心は27〜40歳） |

**時期の窓の文は、その年の運気に合わせる（v2.24）**：交際・出会いの窓の年の一文（「関係が始まって◯年がたつこの年は、〜」「出会いから◯年がたつこの年は、〜」）は、決まった両方向の文ではなく、その年の運気の向きで4つから選ぶ（`depthParts.stage.toned`）。
| 向き | 条件（上から順） | 文の例（交際中・2年目以降） |
| --- | --- | --- |
| 両方（both） | 婚期で大きく動く年、または大きく動く年・動き方が「重なる」 | 関係が深まる流れと、形を組み替える流れが重なり、進むのか距離を取るのかが決まりやすい時期です。 |
| 進む（forward） | 婚期（大きくない）、または関係が動く年で動き方が「育つ」「引き合う」 | 二人の関係が深まり、一緒に過ごす形や将来の話が進みやすい時期です。 |
| 見直す（review） | 信頼の年、または動き方が「揺れる」 | 関係の形を見直し、距離の取り方を考え直しやすい時期です。 |
| 穏やか（steady） | 関係が動かない年 | 大きく形を変えるより、二人のペースで関係を育てていく時期です。 |
- 運気は、**ふたりの時系列では二人の判定**（`pairTone()`）、**ひとりの時系列では、登録した相手の生年月日（`partnerBirth`）があれば二人の判定**、なければ本人の判定（`stageTone()`）。同じ二人なら、ひとりとふたりで同じ向きになる。ただし、ひとりの時系列で本人の婚期の年は、二人の向きが「見直す」なら「両方」、「穏やか」なら「進む」にする（婚期の印と文が食い違わないように）。
- 相手の生年月日は `timelineContext()` で窓の年の向き（`partnerTones`：年→向き）に変えるときだけ使い、鑑定書（カードの計算メタ）には保存しない。保存されるのは向きだけ。
- 文は関係の種類（交際中・片思い・復縁希望/元恋人・夫婦）×向き×（1年目／2年目以降）。1年目は「関係が始まってまだ間もないこの年は」（ひとり・交際中）／「出会ってまだ間もないこの年は」。
- ふたりの時系列の2〜3年目のヒントも向きに合わせる（`stage.toned.decision`・`decisionBy`）。向きの文がある年は、動き方の一文（`qualitySentence`・`qualities.sentence`）を重ねない。
- タグ（「#関係の分かれ道」など）は人生の時期で決まるので変えない。
- 判定（どの年が動く年・婚期か）は変えない。なお、検証では運気で始まりと終わりを見分ける力は確かめられていない（§3）。これは文面の方針としての採用。

### 1-3. 占術の目印（毎年）

**関係の点**
| ID | 内容 | 点 | 時刻 |
| --- | --- | --- | --- |
| R1 | 女性は木星、男性は金星のアンタルダシャーが、その年に90日以上かかる（インド） | 女性3・男性2 | 必要 |
| R2 | 年支が日支（配偶者の位置）と冲・刑・害・破 | 1 | 不要 |
| R3 | 年干が、命式にあるパートナーの星と干合 | 3 | 不要 |
| R5 | 年支が天喜 | 2 | 不要 |

**仕事の点**（2点以上で候補。10年の区切りごとに3年まで）
- 年干が官星・印星（1点）
- 年支が月支と冲・刑・害・破・合（1点）
- 10室のダブルトランジット（1点、時刻が必要）

**住まいの点**（2点以上で候補。10年の区切りごとに2年まで）
- 駅馬（1点）
- 年支が日支・年支と冲（1点）
- 4室のダブルトランジット（1点、時刻が必要）

### 1-4. その年の種類（上から順に決める）
1. **信頼を見直す年**：R2とR3が両方ある。
2. **関係が動く年**：関係の点が2点以上。または、時期の窓の中で1点以上。
   - 強さ：窓の中で2点以上なら「大きく動く」。窓の外では4点以上が「大きく動く」。
3. **仕事の転機**：仕事の候補に選ばれた年。
4. **住まいの変化**：住まいの候補に選ばれた年。
5. **兆しの年**：関係の点が1点（窓の外）。
6. **静かな年**：上のどれにも当たらない。

**動き方の書き分け（v2.18）**：関係が動く年の文とタイトルは、目印の組み合わせで「育つ・揺れる・重なる・引き合う」を書き分けます。ただし「大きく動く年」は、婚期として示す年を除いて、必ず両方向（始まり・深まりと区切りが重なりうる）で書きます。大きな年が始まりになるか終わりになるかを見分ける目印は、データで見つからなかったためです。例：「縁が大きく動く年」「縁が深まる流れと、関係の形を組み替える流れが同じ年に重なります」。

重ねてつく印：
- **婚期**：交際中で関係が動く年、かつ「関係の点＋交際・年代の窓（+1）＋7室のダブルトランジット（+1）」が3以上。
- **（v2.25 で削除）婚期の補完**：v2.19〜2.24 は、交際の窓の3年のどれも婚期にならなければ一番点の高い年を婚期にしていました。交際開始の分かる著名人362人で、婚期の年と結婚の年の一致が偶然と同じ（0.98倍）で、補完があるとほぼ全員（362人中360人）に婚期の印が付くため削除しました（VALIDATION.md §1n）。婚期は通常の条件を満たした年だけです。交際年数による「#関係の形が決まる時期」のタグと文は残します。
- **窓の年の文**：v2.24 から、その年の運気の向きで選びます（1-2 の表）。v2.19〜2.23 の「結婚へ進むのか、距離を取り直すのか」の決まった両方向の文は使いません。
- **人生の転機**：10年の流れ・大周期の切り替わりの年（時刻ありのみ）と、大きく動く年に仕事・住まいが重なった年（10年の区切りの中で2年まで）。
- **時期のタグ**：窓の年に「#縁が動きやすい年代」「#関係の形が決まる時期」「#関係を見直す時期」のどれかをつけます。

### 1-5. 1段落の組み立て（約190〜300字）
1. **リード**：その年の種類（例「この年は、人とのつながりに変化が生まれやすい時期です」）
2. **年表**：その年の出来事と読み解き、または直近の出来事からの年数
3. **人生の時期の一文**：例「関係が始まって3年がたつこの年は、二人の関係の形が決まりやすい時期です」。年代の窓（9年続く）の一文は、窓の最初の年と、関係・信頼・兆しの年にだけ出す（判定には毎年効く）
4. **本人の性質**：生まれた日の干×その年
5. **10年の流れの中での意味**
6. **現れ方・節目**：出来事を年表に入れた年は、予想の文を出さない
7. **才能の土台**：生まれた月の中心の要素×その年
8. **変わり目の月**：時刻があるときだけ
9. **ヒント**：これからの年。過ぎた年は問い（年表に出来事がある年は、その出来事についての問い）
- **長いとき**：分野の一般的な文、10年の流れの文の順に外します。人生の時期の一文は外しません（v2.19）。
- **タイトル**：その年のテーマを言い切る短い形。
- **詳細版**：同じ材料を節に分けて出します（「人生の時期から」の節を含む）。

## 2. 二人分の時系列

### 2-1. 入力
あなたと相手の生年月日（時刻は任意）、関係の種類（片思い・お付き合い中・婚約中・夫婦・復縁希望・元恋人・友人・親）、出会った年、あなたの年表。

### 2-2. 人生の時期の窓（v2.16）
| 窓 | 条件 |
| --- | --- |
| 交際 | 交際中・婚約中で、出会った年から1〜4年がたつ年 |
| 結婚 | あなたの年表の、出会った後の結婚から3〜7年がたつ年（その後に別れ・離婚があれば窓なし） |

### 2-3. 二人の年の種類（上から順）
1. **友人・家族の年**：関係の種類が友人か親。
2. **信頼の年**：どちらかが「信頼を見直す年」。
3. **二人とも動く**：二人とも関係の点が2点以上。
4. **あなたが動く**：あなたが3点以上、または2点以上で相手が1点以上。
5. **相手が動く**：4の逆。
6. **（v2.16）時期の窓で動く**：窓の中で静かな年でも、どちらかに1点あれば動く年。両方1点以上なら「二人とも動く」。
7. **静かな年**：上のどれにも当たらない。

重ねてつく印：
- **婚期**：交際中・婚約中で、二人とも動く年、または片方が動く年で合計5点以上（交際の窓の中なら3点以上）。出会った年は除きます。
- **（v2.21）ふたりの婚期の保証はなし**：v2.19 の「窓の中で1年を必ず婚期にする」は、著名人カップル180組で偶然と同じ当たり（0.87〜1.01倍）だったため外しました（VALIDATION.md §1m）。
- **（v2.21）時期の窓の段階**：出会いから1年目は「出会いが深まる時期」（出会いの勢いのまま距離が縮まり、相手を知っていく。段落は時期の文から始め、問いは出会いの印象について）、2〜3年目は「関係の分かれ道」（結婚か別れのどちらかが最も起きやすい山。180組の約4割がこの2年に集中）、4年目は「関係の形が決まる時期」。窓の年の一文と2〜3年目のヒントは、二人の運気の向き（進む・見直す・両方・穏やか）で選びます（v2.24、1-2 の表）。
- **関係が揺れやすい年**：夫婦の、動く年・信頼の年（v2.21 から夫婦だけ。交際中の別れには効かなかったため。§1m）。年表に出会った後の結婚があれば、結婚の年までは出しません（v2.22）。出会った年・婚期の年・年表に出来事がある年は除きます。
- **ラベルごとの文面（v2.23）**：片思い・復縁希望・元恋人・夫婦（年表に結婚がないとき、または年表の結婚の年まで）も、出会いから1〜4年を同じ窓・同じタグで見ます。窓の中の判定は交際中と同じで、文面をラベルに合わせます（片思い「思いを伝えるのか、距離を保つのか」、復縁・元恋人「二人の関係が進むのか、区切りを迎えるのか」、夫婦「一緒の暮らしの形や役割など」）。夫婦の出会いの窓では、動く年への昇格と揺れやすい年は使わず、2〜4年目のタグは「#暮らしの形が固まる時期」です。
- **時期のタグ**：交際中・婚約中は出会いから1年目「#出会いが深まる時期」、2〜3年目「#関係の分かれ道」、4年目「#関係の形が決まる時期」。夫婦の窓は「#関係を見直す時期」。
- **人生の転機**：どちらかの大きな流れが切り替わる年。

### 2-3b. ひとりの時系列との揃え方（v2.20）
- 二人それぞれの時系列を、出会った年を「今の相手と出会った年」として入れた状態で計算します（`pairContexts()`）。
- 交際中・婚約中・夫婦の「現れ方」の文は、ふたり用の文ではなく、**あなたのひとりの時系列の文**をそのまま使います。相手だけが動く年は相手の文を「相手」に置き換えて使います。ひとりの時系列と食い違わないようにするためです。
- 年の種類（動く年・揺れやすい年）の判定は v2.19 のふたりの判定のままです。ひとりの判定を重ねる形も試しましたが、離婚した夫婦75組で離婚の年を拾う力が 1.77倍→1.05倍に落ちたため、採用していません。
- 時期の窓の文とヒントは、2-3 の「時期の窓の段階」と、運気の向き（1-2 の表、v2.24）で決まります。
- 揺れやすい年には、一方向の動き方の文（育つ・深まる）を入れません。

### 2-4. 1段落の組み立て（約190〜300字）
1. **リード**：出会った年は「二人が出会った年」
2. **揺れやすい年の一文**：該当する年だけ
3. **人生の時期の一文**：例「出会いから3年がたつこの年は、二人の将来の形を話し合いやすい時期です」
4. **あなたの年表**：出会った年以降の恋愛の出来事だけ
5. **二人のテーマ**
6. **二人それぞれの性質**：相手の文は「あなた」を「相手」に置き換え
7. **現れ方**
8. **節目**：婚期・転機
9. **ヒント・問い**
- 片思い・元恋人は離れている二人向けの文にし、一緒の暮らしを前提にしません。
- 「別れやすい」「離婚しやすい」とは書きません。

## 3. 当たり方（著名人での検証）

| 判定 | 出来事を拾う割合 | 印の年の割合 | 偶然との比 |
| --- | --- | --- | --- |
| 旧：占術だけの「関係が動く年」 | 16% | 13% | 1.29倍 |
| 新：関係が動く年（確認用） | 22% | 18% | 1.17倍 |
| 新：大きく動く年（確認用） | 5% | 3% | 1.53倍 |
| 新：関係が動く年＋時期の年（確認用、年表なし） | 44%（始まり52%） | 33% | 1.25倍（始まり1.48倍） |
| 同（確認用、年表あり） | 50% | 37% | 1.29倍 |
| 二人の動く年（離婚した夫婦75組、結婚期間の中で比べた場合） | ― | ― | 1.77倍 |
| ふたりの婚期の年（交際開始の分かるカップル180組、v2.19） | 21% | ― | 0.87〜1.01倍（偶然と同じ） |
| ふたりの時期の窓（同、出会いから1〜4年目） | 結婚70%・別れ73% | 4年 | ― |
| 同、2〜3年目（関係の分かれ道） | 39% | 2年 | ― |

- **使わない見方**：紫微斗数、九星、六星占術（大殺界）、宿曜、数秘術、西洋（角度・食・進行）、インド（ヨーギニーなど）は、確認用のデータで再現しなかったため、判定には使っていません（VALIDATION.md §1g〜§1k）。
- **見せ方**：判定は予言ではなく、振り返りと心構えのための読み物です。タグは「候補」と表記し、根拠の欄に年齢・交際の年数の傾向も使っていることを書きます。

## 4. コードの場所
- 一人分の判定：`signals.ts`（`lifeStage`・`baseDecisionUncached`・`regularMarriage`・`decideYear`）
- 二人分の判定：`couple.ts`（`pairContexts`・`pairStage`・`pairBase`・`decidePairYear`）。現れ方の文は `compose.ts` の `composeYear().relLines`
- 文章：
  - 一人分：`compose.ts`
  - 二人分：`couple.ts`
  - 部品：`personal.ts`・`lifeline.ts`・`depth.ts`・`areas.ts`
- 原稿：`data/*.json`（時期の文は `depthParts.json` の `stage`）
