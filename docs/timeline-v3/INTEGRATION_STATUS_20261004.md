## 実装

- 自己鑑定の生成・保存済み鑑定の再表示・過去年、ふたりの時系列を環境変数でv3に接続。
- 性格文・相性の本質の生成は既存経路を維持。
- 新規時系列には必要な出生入力のみ渡し、計算済み命式全体が各年のメタデータに重複しないようにした。
- 任意の関係状況を出生スナップショットに保持。保存済み鑑定に現在の関係状況を上書きしない。
- 年表、本人プロフィール、独立した任意同意のAPI/UIを追加。
- 年表を別の出生情報へ流用しないため照合、SQLのプロフィール行ロック、プロフィール変更ガードを追加。
- 年表の全件更新は単一トランザクション。所有者RLS、100件上限、出生年〜現在年の制限、アカウント削除時の連動削除。
- 検証出力の純粋関数は現在の同意がある行のみ処理し、識別子・自由文を除外。実データの出力は未実施。
