# ふたりの時系列 v3 実装仕様（Codex向け）

現行の `coupleAllYears`（2人の日柱と宿曜の組み合わせで選ぶ固定文）を、本人の時系列 v3 と同じ判定を2人に当てて組み立てる方式に置き換えます。参照実装：`backend/src/lib/report/timelineV3/couple.ts`、原稿：`data/pairParts.json`。

> **最新の判定と文章は §2・§3f〜§3h と `LOGIC.md` §2 が正です。** §3e までの古い記述と食い違うときは、新しい節（番号が後の節）を優先してください。

## 1. 入力（新しい入力は不要）

| 項目 | 取得元 |
| --- | --- |
| あなたの出生情報 | 相性鑑定書の `birth_data.self`（既存の `coupleSnapshot().a`） |
| 相手の出生情報 | `birth_data.partner`（`coupleSnapshot().b`。相手の性別・出生地は登録時に必須、出生時刻は任意） |
| 関係のラベル | `relationshipLabel`（片思い・お付き合い中・婚約中・夫婦・復縁希望・元恋人・友人・親） |
| 出会った年 | 既存の `couple_timeline_settings`（恋愛のラベルすべての「時期の窓」の起点（v2.23 から片思い・復縁希望・元恋人・夫婦も）。二人それぞれの文脈の `partnerSince`・`partnerKind` にも入る） |
| あなたの年表 | `self.lifeEvents`（任意。出会った年以降の結婚があれば夫婦の窓、文の言い直し） |

ラベル → 状況：片思い＝crush、お付き合い中＝partnered、婚約中＝engaged、夫婦＝married、復縁希望・元恋人＝former、友人＝friend、親＝family（`pairParts.json` の `labelStatus`）。

## 2. 判定（`decidePairYear`）

2人それぞれに本人の時系列と同じ `yearSignals` を計算し、関係点（R1〜R5。R4は0点）をあなた＝A、相手＝Bとする。

| 主題 | 条件（上から順に） | 強さ |
| --- | --- | --- |
| friend | 友人・親のラベル（パートナーの時期の判定は使わない） | 静か |
| trust | どちらかの年が本人の時系列で「信頼を見直す年」（R2とR3が同時） | 大きく（どちらかの点が4以上）／動きやすい |
| both | A≥2 かつ B≥2 | 大きく |
| self | A≥3、または A≥2 かつ B≥1 | 動きやすい |
| partner | B≥3、または B≥2 かつ A≥1 | 動きやすい |
| quiet | それ以外 | 静か |

片側だけの年は、本人の時系列より1段高い条件にしている（2人分の和集合で「動く年」が増えすぎないため。見本で12年中6年）。

- **時期の窓での昇格（v2.16）**：交際の窓（出会いから1〜4年）・夫婦の窓（年表の結婚から3〜7年）の中では、quiet でもどちらかに1点あれば動く年（両方1点以上なら both）。
- **結びつきの時期**：お付き合い中・婚約中、2人とも18歳以上、出会った年ではない、夫婦の窓の中ではない、かつ（both、または片側で A+B≥5。交際の窓の中は A+B≥3）。v2.19 の「窓の中で1年を必ず婚期にする」保証は v2.21 で廃止。
- **章**：どちらかの大運・大周期の開始がある年は「人生の転機」タグ（主体をA/B/ペアで記録）。
- 相手の出生時刻がないときは相手側のインド占星術を使わず、根拠欄にその旨を書く。
- 男性の R1（金星の期間）は未検証（本人の時系列と同じ扱い）。

## 3. 文章

| セクション | 内容 |
| --- | --- |
| ふたりのこの年 | 出会った年は「二人が出会った年です。」（主題の導入文は出さない）、それ以外は主題の導入文（3種。片思い・元恋人の静かな年・信頼の年は `apart`）＋「あなたは〇〇、相手は〇〇が主題になる年です。」（2人の十神。同じなら「二人とも〜」）＋出会った年は、あなたの十神の「始まり」の読み解き |
| 動き方の質 | 本人の時系列と同じ4種。動いている側（both は2人分）の判定から決め、「ふたりのこの年」に質の一文（`qualitySentence`）を入れ、現れ方の先頭の方向を合わせる |
| 二人の間に表れること | **（v2.20 で変更：交際中・婚約中・夫婦の現れ方は §3g のとおり、ひとりの時系列の文を使う。下は出会った年・片思い・元恋人・友人・親と、二人のどちらかが18歳未満の年の扱い）** 出会った年は「出会い」の9文（関係ラベルに関係なく）。元恋人の過去の年は、別れた時期が分からないので中立の文（本人の時系列の `unknown`）。それ以外は主題×状況の9文から選ぶ（本人の時系列と同じ `pickPossibilities`。0・3・6＝始まり・前進、1・4・7＝深まり・見直し、2・5・8＝区切り・距離）。どの組（0〜2、3〜5、6〜8）から取るかは「二人とも18歳以上の年で、同じリストを使った年が何回目か」（`setSeed`）で順に回す。関係が動く3種（both/self/partner）は同じリストなので合わせて数える。静かな年は二人の日常の9文から2文。友人・親は専用の9文。片思い・元恋人の静かな年も各9文。続けて結びつき・章の一文 |
| 二人で過ごすヒント | 主題ごとに3種。過去の年は「二人で振り返る問い」（`reflection`）。片思い・元恋人は見出しを「これからのヒント／振り返りの問い」にし、一緒の暮らしを前提にしない `apart` の文を使う |
| これからの大きな流れ | 章の開始がある年だけ。「あなた：〜」「相手：〜」 |
| 根拠と期間 | 「あなたの命式では〜」「相手は〜」の平易な根拠。専門用語は `evidence.detail` のみ |

### 3b. 厚み（v1.9）

二人とも18歳以上の年に追加（`depthParts.json` の `pair`）：

| 追加 | 内容 |
| --- | --- |
| ふたりのこの年（末尾） | 二人それぞれの追い風・半々・踏ん張りどころ（本人の時系列と同じ計算）＋二人の組み合わせの一文（今年以降のみ。各3種を `j` で） |
| ふたりの10年の流れ | 「あなたは「{大運の章の見出し}」の{n}年目です。」「相手は〜」＋同じ系統か違う系統かの一文（各3種）。大運が出ない側（出生時刻・性別なし）は「〜読めるようになります」 |
| ふたりのこの年の時期 | 本人の時系列の「この年の時期」を「あなた：」「相手：」で並べる（段落の間は空行）。相手の出生時刻がなければ「相手：出生時刻が分かると〜」。二人の最初の変わり目の月が1か月以内なら、重なる月の一文 |
| 二人の前後の年とのつながり | 恋愛系のラベルのみ。前年と今年の二人の主題を「動く（both/self/partner）・信頼・静か」の3分類で9通り（3〜6種、生まれてから同じ接続が何回目かで回す）＋次に二人の関係が動く年（12年先まで） |

| 二人それぞれのこの年 | 「あなた：」「相手：」で、それぞれの十神の「人との関わり」の1文目（`areaParts.json` の `rel`。あなたは `i`、相手は `i+1` の変種）。過去の年は過去形 |
| 二人で過ごすヒント／振り返る問い（2文目） | 二人の主題ごとの一文を続ける（`pair.themeAdvice`／`pair.themeReflection`。関係が動く・信頼は各3種、静か・友人は各6種）。片思い・元恋人は `pair.themeApart`（各6種）。「二人とも18歳以上の年で同じ主題が何回目か」で回す |

**出会った年（恋愛系ラベル）**：その年の二人の主題に関係なく、始まりとして読む。見出しの後半は `pair.meeting.tails`（3種）、「二人の前後の年とのつながり」の1文目は「この年が、二人の関係の始まりです。」、ヒント／問いは `pair.meeting.advice`／`reflection`（各2文）に置き換え、関係が動く・信頼のタグは付けない（`#出会った年` のみ）。相手の10年の流れが出ないとき、性別が分かっていれば「出生時刻が分かると読めるようになります」とする。

二人で過ごすヒント／振り返る問い、動き方の質の一文は、隣の年で重ならないよう `j = year % 3` で選ぶ（v1.9 で `i` から変更）。

見出し：`あなたの十神の書き出し[i]` ＋「、」＋`主題の後半[j]`（`i = floor(year/10)%3`、`j = year%3`）。

### 3c. 二人それぞれの性質（v2.12）

本人の時系列と同じ `personalLines()`（`personal.ts`）を2人に使う。18歳以上の人だけ。
- 相手の文は、原稿の「あなた」を「相手」に置き換えて使う。原稿は、性質の文に「あなた」がちょうど1回入り、「相手」は入らないように書いてある（テストで確認）。
- 「二人それぞれのこの年」（詳細版）：それぞれ、性質の文と、その人の人との関わり方の1文を並べる。
- 1段落版：二人のテーマの文の後に、あなたの性質の文と相手の性質の文を入れる。その分、現れ方は1文にする。190字に届かない年は2文目も戻す。
- 根拠：`A:本人の性質：日干…` と `B:本人の性質：日干…`。

### 3d. あなたの年表（v2.14）

`self.lifeEvents`（本人の年表）を `pairLifeLines()`（`lifeline.ts`）で文に入れる。判定は変えない（テストで確認）。
- 使うのは、**出会った年以降の、あなたの関係の出来事だけ**（交際の始まり・復縁・結婚・別れ・離婚）。それより前の出来事は別の人とのことかもしれないので使わない。「出会い」は出会った年の入力と重なるので使わない。相手の年表は扱わない。
- 片思い・友人・家族では使わない。出会った年がない場合も使わない。
- 出来事のあった年：「あなたの年表では、この年（の◯月）に◯◯がありました。」。1段落版では「〜形で表れることがあります」を出さない。過去の年の問いは、その出来事についての二人の問い（別れ・離婚はあなたへの問い）。
- 出来事のない年：直近の出来事（なければ出会った年）からの年数。二人の関係が動く年・信頼の年か、1・3・5・10…年目の節目。別れ・離婚からの年数は、動く年で3年以内だけ。
- 詳細版は「あなたの年表から」の節（二人それぞれのこの年の前）。

### 3e. 関係が揺れやすい年（v2.15）

- **対象**：夫婦の二人だけ（v2.21。交際中・婚約中は対象外：交際中の別れの年には効かなかったため、VALIDATION.md §1m）。二人の判定が「動く年」（both／self／partner）か「信頼」の年。
- **除外**：出会った年、婚期の年、あなたの年表に出来事が入っている年は除く。
- **新しいルールではない**：既存の判定をそう呼ぶだけ。根拠は VALIDATION.md §1g・§1h（著名人夫婦75組で、離婚した年がこの年に入る割合は、同じ結婚のほかの年の約1.8倍）。
- **文**：`depthParts.pair.sway`。
  - リードの次に「関係が深まる方向にも、ぎくしゃくする方向にも動きやすい年です。」などを置く（3種）。
  - 過ごし方・問いは揺れの年用に差し替える（3種ずつ）。
  - 1段落版のタイトルは「関係が揺れやすい年」「二人の形を見直す年」「揺れを越えて深まる年」。
  - 種類は、出会った年より後の同じ種類の年の数で回す。
- **禁止**：「別れやすい」「離婚しやすい」とは書かない（テストで確認）。
- **タグと根拠**：タグは `pair-sway`「#揺れやすい年」。根拠の欄に、呼び方の意味と、別れを予言するものではないことを書く。
- **長さ**（v2.20 で変更、§3g）：交際中・婚約中・夫婦は、二人のテーマの文→動き方の文→現れ方の順に外す。それ以外は旧規則：1段落版が300字を超えるときは、「表れること」の文、二人のテーマの文の順に外す。

### 3f. 人生の時期（v2.16、`pairStage()`）

- **窓**：
  - 交際中・婚約中は、出会った年から1〜4年がたつ年（`dating`）。
  - あなたの年表に出会った後の結婚があれば、そこから3〜7年がたつ年（`married`）。結婚の後に別れ・離婚があれば窓なし。夫婦で結婚の年が分からなければ窓なし。
- **判定**：窓の中では、静かな年でもどちらかに1点あれば「動く年」（両方1点以上なら二人とも動く）。婚期は、交際の窓の中なら合計3点で判定する（窓の外は5点）。
- **（v2.21 で廃止）婚期の保証（v2.19）**：交際中・婚約中で、出会いから1〜4年のどれも婚期にならないときは、`decidePairYear()` が窓の中の1年を婚期にする（`pairBase()` の点の合計、動く年+1、信頼の年は除く、同点は2年目に近い年→早い年）。静かな年なら点の多い側の動く年にする。
- **文**：リードの次に時期の文を入れる（交際・出会いの窓は `depthParts.stage.toned`〈§3j〉、夫婦の年表の窓は `pairMarried`）。年表の経過年数の文とは重ねない。
- **タグと根拠**：タグは `pair-stage`。根拠の欄には `stage.evidence` を入れる。

### 3g. ひとりの時系列の文を使う（v2.20）
- `buildCoupleTimelineV3()` は `pairContexts()` で二人の文脈を作る（ふたりの関係の種類を `relationshipStatus` に、恋愛のラベルなら出会った年を `partnerSince`、ラベルの種類を `partnerKind` に入れる。v2.23）。
- 交際中・婚約中・夫婦（二人とも大人）の現れ方は、`composeYear(a).relLines`（相手だけが動く年・相手だけが信頼の年は `composeYear(b).relLines` の「あなた」を「相手」に置換）。
- 1段落版が長いときは、二人のテーマの文→動き方の文→現れ方の順に外す（現れ方は最後まで残す）。揺れやすい年は動き方の文を入れない。
- 時期の文・ヒントの選び方は §3h（v2.21）。
- 判定（`decidePairYear()`）は二人の点数の判定のまま（§2）。ひとりの判定を重ねる案は離婚夫婦75組で 1.05倍（v2.19 は 1.77倍）だったので不採用。

### 3h. 婚期の保証をやめ、時期の窓を段階で見せる（v2.21）
- `decidePairYear()` は `pairBase()` そのまま（v2.19 の婚期の保証を外す。§1m で偶然と同じだったため）。
- 時期の文：v2.24 から §3j（運気の向きで選ぶ）。タグ：1年目 `stage.tags.pairStart`「#出会いが深まる時期」、2〜3年目 `pairPeak`「#関係の分かれ道」、4年目 `dating`。
- ヒント：2〜3年目は `stage.toned.decision`（向きごと、§3j）、1年目は `stage.pairFirst`（出会いの印象・惹かれたところ）。
- 1年目の1段落版は、二人のテーマのリードを出さず、時期の文（「出会ってまだ間もないこの年は…」）から始める。タグは「#出会いが深まる時期」。
- 揺れやすい年は夫婦だけ（交際中の別れでは 0.89倍）。v2.22：あなたの年表に出会った後の結婚があれば、結婚の年までは出さない。

### 3i. どの恋愛のラベルでも出会った年を使う（v2.23）
- 時期の窓（出会いから1〜4年）は、お付き合い中・婚約中に加えて、片思い・復縁希望・元恋人・夫婦（年表に出会った後の結婚がないとき、または年表の結婚の年まで）でも開く。窓の中の判定（静かな年でも1点で動く年）は交際中と同じ（夫婦を除く）。タグは同じ（1年目「#出会いが深まる時期」、2〜3年目「#関係の分かれ道」、4年目「#関係の形が決まる時期」）。夫婦だけ2〜4年目を「#暮らしの形が固まる時期」（`stage.tags.pairMarried`）にする。
- 文面：`stage.toned.body.{crush|former|married}`（§3j）、ヒント `stage.toned.decisionBy`・`stage.pairFirstBy`。
  - 片思い：「思いを伝えるのか、距離を保つのか」「このまま思いを温めるのか、一歩踏み出すのか」。
  - 復縁希望・元恋人：「二人の関係が進むのか、区切りを迎えるのか」「この先どうしたいのか」。一緒にいる前提の言い方はしない。
  - 夫婦：「一緒の暮らしの形や役割など」「これからの暮らし方」。結婚するかどうかの話はしない。
- 夫婦の出会いの窓では、静かな年の「動く年」への昇格をしない。「揺れやすい年」も出さない（結婚前の年が多く、離婚夫婦の根拠は結婚期間の中のものなので）。離婚夫婦75組の 1.77倍は変わらない。
- 婚期は今までどおり、お付き合い中・婚約中だけ。
- ひとりの時系列も同じ：`partnerKind` があれば状況に関係なく `partnerSince` から1〜3年が交際の窓になり、文面は `stage.toned.body.{crush|former|married}`（§3j）。婚期は通常の判定条件を満たした年だけ（v2.25 で補完を削除）。

### 3j. 時期の窓の文は二人の運気に合わせる（v2.24）
- 交際・出会いの窓（出会いから1〜4年）の一文を、その年の二人の運気の向き（`pairTone()`：進む・見直す・両方・穏やか）で選ぶ。条件と文の例は `LOGIC.md` 1-2 の表。
- 文：`stage.toned.prefix.pair`（1年目「出会ってまだ間もないこの年は、」／それ以降「出会いから{k}年がたつこの年は、」）＋`stage.toned.body[ラベルの種類][向き][1年目なら0、それ以外1]`。
- 2〜3年目のヒント：`stage.toned.decision[向き]`（片思い・復縁/元恋人・夫婦は `stage.toned.decisionBy[種類][向き]`）。
- 窓の年は、動き方の一文（`qualitySentence`）を重ねない（向きの文が同じことを言うため）。
- 判定・タグは変えない。ひとりの時系列も、相手の生年月日（`partnerBirth`）があれば同じ `pairTone()` を使うので、同じ二人なら向きがそろう（本人の婚期の年だけは「見直す」→「両方」、「穏やか」→「進む」）。相手の生年月日は向き（`partnerTones`）に変えて捨て、鑑定書には保存しない。

## 4. タグ

`#出会った年`（入力事実）/ `#二人の関係が動く時期`（pair）/ `#関係が動く時期`（A または B）/ `#信頼を確かめ直す時期` / `#結びつきの時期` / `#人生の転機` / `#揺れやすい年`（夫婦だけ、`pair-sway`）/ 時期の窓（`pair-stage`、恋愛のラベルすべて）：`#出会いが深まる時期`（出会いから1年目）・`#関係の分かれ道`（2〜3年目）・`#関係の形が決まる時期`（4年目）・`#暮らしの形が固まる時期`（夫婦の2〜4年目）・`#関係を見直す時期`（年表の結婚から3〜7年）。現行の `#乗り越えるべき壁の到来`・`#婚期`・`#出会いの時期` は v3 では出さない。

   ```ts
   }
   ```
   応答の形（`status`・`years`・`collapsedYears`・`groups`・`entries[{year,label,contentStatus,card}]`・`meetingYear`）は現行と同じ。追加で `relationshipStatus` を返す。
2. `snapshot.a/b` を `TimelineV3Input` として渡す（`birthTime: null` は `undefined` に変換）。あなたの年表があれば `self.lifeEvents` に入れる（`canonicalLifeEvents()` で整える）。関係の種類と出会った年から二人の文脈を作る処理（`pairContexts()`：`relationshipStatus` と `partnerSince` の上書き）は `buildCoupleTimelineV3()` の中で行うので、呼び出し側では不要。
3. iOS：ふたりの時系列の年カードは、現行は見出しなしの1セクション。v3 は4〜5セクション（見出しあり）になるので、本人の時系列カードと同じ表示部品で `sections` を描画する。新しいタグの表示色を追加。
4. 切り替え：ステージングで `COUPLE_TIMELINE_ENGINE=v3`。問題があれば外すと現行に戻る。
