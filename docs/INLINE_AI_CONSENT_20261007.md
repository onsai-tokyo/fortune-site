# AI相談と鑑定書の利用枠表示の修正

- 審査アカウントの6通は会員分3通＋審査用追加分3通。2026-10-07のDB照会で確認。過去2期間の会員分は失効済み。
- 会員分は更新ごとに3通。通常の未使用分は繰り越さない。失敗時の利用枠回復は既存仕様を維持。
- APIにreviewRemainingを追加し、審査用付与を単品購入分と分ける。合計残数は変更しない。
- iOSの相談画面と鑑定書作成画面に、送信先・目的・送信情報・プライバシーリンクを表示。
- 「同意して送信」「同意して鑑定書をつくる」を明示的な今回の送信同意とする。別画面・追加スイッチは使わない。
- 再送も同意を明示。利用プランを見るボタンからは、更新により利用枠が復活しても自動的にAI送信しない。
- 利用規約だけでの黙示的同意には変更しない。バックエンドの同意ヘッダー検証、アカウント分離は維持。
- Webの既存確認ダイアログは今回のiOS変更の対象外。

Apple根拠: https://developer.apple.com/app-store/review/guidelines/#data-use-and-sharing
Appleは外部AIへの送信先の開示と送信前の明示的同意を要求する。画面内に組み込む方式はこの要件を満たすための実装方針で、審査通過を保証するものではない。

検証状況: サーバー同意8件・鑑定書14件成功、TypeScriptビルド成功。iPhone 17 Simulatorへ切り替えた後、iOS 135件（2件スキップ、失敗0）成功。鑑定書作成画面のインライン説明・送信ボタンをSimulatorで確認。ビルド108で配信する。
