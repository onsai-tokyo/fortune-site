# Fate Lab SEO運用手順

最終更新日: 2026-08-11

## ブランド表記

外部プロフィール、プレスリリース、動画説明欄では次の表記を統一する。

- サービス名: Fate Lab（フェイトラボ）
- URL: https://fate-lab.com/
- 運営: 温齋株式会社
- 説明: 東洋・西洋・インドの9つの占術を固定ルールで統合する、生年月日の無料オンライン占い

`Fortune Lab`、`fortune-lab`、`fotune-lab` は自社サービス名として使用しない。

## 優先して整備する外部プロフィール

1. 温齋株式会社の公式サイトからFate Labへ、サービス名をリンク文言にして掲載する。
2. X、Instagram、YouTube、noteなど、実際に運用できる公式アカウントだけを作成する。
3. 各プロフィールでサービス名、説明、URL、ロゴを統一する。
4. プレスリリースまたは開発ストーリーを公開し、計算の再現性と9占術の統合方法を説明する。
5. 占術家・編集者・利用者に、実際に利用したうえでの率直なレビューや紹介を依頼する。

リンク購入、大量相互リンク、無関係なディレクトリへの一括登録は行わない。

## 紹介依頼文テンプレート

件名: 生年月日占い「Fate Lab」のご紹介・ご意見のお願い

> Fate Lab（フェイトラボ）は、四柱推命、紫微斗数、西洋占星術、インド占星術など9つの占術を同じ出生条件から個別に計算し、複数の体系で一致した傾向をまとめる無料サービスです。結果を一度お試しいただき、読者の方に役立つとご判断いただける場合に限り、ご紹介をご検討いただけますと幸いです。記事内容へのご意見や計算上の誤りのご指摘も歓迎しています。

URL: https://fate-lab.com/

## プレスリリース骨子

- 見出し: 9つの占術を固定ルールで統合する無料生年月日占い「Fate Lab」を公開
- 課題: 占いサイトごとに結果や根拠が異なり、利用者が比較しにくい
- 特徴: 同じ入力なら同じ計算結果、時刻不明時は推測しない、複数占術の一致点を優先
- 対応占術: 四柱推命、算命学、納音、宿曜、九星気学、数秘術、紫微斗数、西洋占星術、インド占星術
- 運営会社と問い合わせ先
- サービスURLとOG画像

## 毎週のSearch Console確認

1. 過去28日とその前の28日を比較する。
2. 表示回数、クリック数、CTR、平均掲載順位をページ・検索語別に確認する。
3. 掲載順位8〜20位で表示回数の多いページを優先して加筆する。
4. 順位が高くCTRが低いページは、検索意図に合わせてタイトルと説明文を改善する。
5. インデックス未登録、クロールエラー、Core Web Vitals不良を確認する。
6. 実質的に更新したURLだけ再クロールを申請する。

## 月次コンテンツ監査

- 計算例、境界条件、独自検証のいずれかが記事に含まれているか
- 記事の主張と実装の計算仕様が一致しているか
- 類似記事同士で検索意図が重複していないか
- 古い記事の日付だけを変更していないか
- 関連記事と無料鑑定へのリンクが機能しているか
- 医療、法律、金融、採用を占いだけで判断させる表現がないか
