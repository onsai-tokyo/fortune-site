# 鑑定カードの単品購入・会員見放題（2026-10-05合意）

## 商品・対象

- 相性：友人・恋人・結婚・関係が始まるきっかけは無料。
- 相性：良好な関係を築くコツ／障害になること／復縁の可能性は、相手1人×1項目ごとに300円（日本価格）。
- 時系列：2026年まで無料。2027年以降は本人1人または二人1組×西暦1年ごとに300円。年境界は固定し、翌年に自動移動しない。
- 月額会員：上記カードを会員期間中はすべて閲覧可能。自由記述の相談鑑定書は初月から毎月3通を維持。
- 単品購入した項目は、会員解約後も閲覧可能。返金・取消時は該当購入による権利を取り消す。
- 既存の相談鑑定書1通購入（com.onsai.fatelab.report.single）とは別商品。

## 表示

カードの写真・タイトル・年を維持し、鍵と「単品購入／会員で読む」を表示。本文・鑑定タグ・根拠は購入前に配信しない。
タップすると下からシートを表示。対象（相手・項目・年）、単品価格、月額料金、権利の範囲、復元、規約・プライバシーリンクを表示する。
価格はStoreKitから取得。未取得時は300円を購入価格として表示せず、購入を無効にする。

## 購入の保存

相手の登録名や表示タイトルを購入キーにしない。アカウント・本人の出生条件・相手の識別子・項目ID/西暦年を使う。
再鑑定しても同一対象は買い直し不要。別の相手や出生条件へ購入権利を移さない。
購入完了はApple検証とサーバー保存を確認してからTransaction.finishする。
遅延承認、アプリ終了、再送、返金、別アカウントへの切替を検証する。

## 公開条件

この仕様はビルド100に含まれていない。新商品の登録・価格300円の確認、権利DB、本文のサーバー制限、購入と復元の実機検証、新ビルドの審査が揃うまで本番の鍵を有効にしない。
古いアプリ・保存済み全文・生成SSE・時系列API・相談引継ぎ経由も権限制御の対象。

- 購入台帳は取引と環境を一意に保存し、同時利用を直列化。別ユーザー、二重付与、同じ対象の再消費、返金後の再送による復活を防ぐ。
