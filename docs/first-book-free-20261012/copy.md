# 表示文・審査メモ案（公開・送信は未実施）

## ビルド140／無料OFFで審査する場合
AI鑑定書の作成には会員登録が必要です。月額1,980円で毎月3通、年間12,000円で毎月5通。会員は利用枠を使い切ったあと、1通980円で追加購入できます。性格・相性・年表の鑑定カードは無料で閲覧できます。

審査メモ：本ビルドは無料体験を提供していません。鑑定書作成ボタンから会員プランを選択し、Appleの購入処理を完了すると、入力済みの相談を保持したまま鑑定作成へ戻ります。初回作成前には、外部AI（Anthropic）への送信内容と利用条件について同意を確認します。審査用アカウントのログイン情報はApp Store Connect専用欄に設定します。

## ビルド141／無料ONとして審査する場合のみ使う案
FATE LABは、あなたやふたりの命式と、入力した相談に基づくオリジナル鑑定書を作成します。条件を満たす未加入の方は、1アカウント・1端末につき最初の1通を無料で体験できます。無料枠の有効期限は付与から30日間です。無料受付は日本時間の月ごとに上限があり、上限到達時は会員プランをご案内します。無料体験だけで自動課金されることはありません。

続けて相談するなら、月額1,980円で毎月3通、年間12,000円で毎月5通。会員は利用枠を使い切ったあと、1通980円で追加もできます。完成した鑑定書は本棚で読み返せます。

作成ボタン：最初の1通は無料｜鑑定する
作成画面：最初の1通は無料です。2通目からは会員プランで続けて相談できます。
期限表示：無料枠の有効期限：［サーバーから取得した日時］
上限時：今月の無料体験の受付は終了しました。会員プランで続けて相談できます。
納品後：続けて相談するなら、会員プランで。
課金画面：入力した相談はそのままに。会員プランで続けて相談できます。

審査メモ案：新規の未加入アカウントは、DeviceCheckによる端末確認に成功した場合、1アカウント・1端末につき最初の鑑定書1通を無料で作成できます。無料枠は付与から30日で失効します。無料利用によってサブスクリプションが開始することはありません。無料体験後は会員プランで続けて相談できます。追加1通980円の購入は、会員が利用枠を使い切った場合のみ可能です。

確認手順：未加入の審査アカウントでログイン→本人または相手を登録し、もとになる鑑定を保存→鑑定書タブで相談文を入力→初回のAI利用条件に同意→無料1通を作成→本棚から完成した鑑定書を閲覧→次の相談で会員案内→Appleの購入→相談文を保持して鑑定を作成。DeviceCheckは実機で確認します。同じ端末で無料1通を使用済みの場合は無料枠を再付与しません。

## プライバシーへの追記案（DeviceCheck部分）
初回無料の重複取得を防ぐため、AppleのDeviceCheckに端末の無料体験利用状態を記録します。当社は端末確認用トークンをAppleに送信し、処理の再試行を安全に行うための受付ID・トークンのハッシュ・処理状態を保持します。アカウントを削除しても端末の無料体験利用状態はリセットされません。これらは無料体験の重複取得防止に使用し、広告や外部AIには提供しません。

利用分析の説明・プライバシーマニフェストは140用変更に含めました。App Store Connectのプライバシー回答（利用データ／製品の操作・購入履歴・ユーザーIDと分析目的）との整合は、公開前にオーナーが確認してください。

無料ONの説明は、実機確認と設定を揃えた版の審査時に使います。OFF版だけを審査に出して、審査後に未確認の無料機能へ切り替える前提にはしません。
