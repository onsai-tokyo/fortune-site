## 実装
- 登録完了、年表表示、鑑定ボタン、課金画面、検証済み購入、無料付与・受付・納品を計測。再送重複を除外。相談文・出生情報は行動計測に保存しません。
- AI試行ごとの使用量を追記保存。失敗した応答も記録し、応答不明はゼロ扱いしません。初回＋追記最大2回、合計最大3回。計測開始の保存に失敗したら外部AIを呼びません。
- 無料は初期OFF、付与から30日、JST月500件の無料注文受付上限。同一注文の再送は再消費しません。失敗は枠返還、月の受付件数は戻しません。
- DeviceCheckに成功した端末／アカウントへ1通。成否不明が5分を超えた受付は本人だけ保留し、他ユーザーの付与は再開。期限切れの古い処理による付与をDBで拒否します。
- 139の購入復旧・返還・復元・料金画面を維持。無料→会員→追加購入の順。加入後も無料残を保持するため月額3＋無料1＝4通、年間5＋無料1＝6通になり得ます。繰り越しではありません。
- 無料の後は会員プランへ案内。会員は利用枠を使い切ったあと1通980円で追加可能。相談文を保持して購入から復帰します。
- 実モデル・価格は決め打ちしていません。費用10〜20円はオーナーの暫定判断で、実測原価ではありません。
