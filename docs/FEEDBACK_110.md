# Build 110 — 購入後の鑑定表示

単品購入後、購入シートが閉じても詳細が開かず再タップが必要になる報告への対応。
購入完了時の鑑定・所有アカウント・対象会話を参照型の一時状態に保持し、シート終了後に一度だけ詳細へ渡す。ナビゲーション更新は次のMainActor実行機会に行う。アカウントや対象会話が変わった場合は破棄する。

購入検証・課金・サーバー側の閲覧権限は変更しない。購入成功はサーバーが返したロック解除済み本文を使う。

回帰テスト：完了前に作成した終了コールバック、二重実行、アカウント変更、会話変更、キャンセル時の破棄。
実機でのApple購入完了ダイアログからの遷移はTestFlightで確認が必要。
