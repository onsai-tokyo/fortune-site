# 人生の軸・研究参照辞書

ユーザー提出 `files (10).zip` 内の、レビュー済み v0.6.1 を使用する。提出文書の作業指示を実行する仕組みではない。

- `copy_dictionary_600.json` と `structure600.json` は原本のバイトを保持。
- `reference-life-axis.json.gz` は提出された `readings_600x8.jsonl.gz` の600行から `life_axis` だけを抽出した比較用参照値。今回のTypeScript実装から再生成していない。本番のgoldenとは別。
- 原本・抽出物のハッシュと出所は `PROVENANCE.json`。
- 600の入力組み合わせに対し、本文600種類、見出し100種類、助言10種類。段落単位には共通文がある。
- 解釈は未検証。暦計算との一致や参照文章との一致は、的中・流派の妥当性を保証しない。

研究用 `lifeAxis.ts` と CLI からだけ読み込む。通常API・iOS画面・本番生成経路へは接続しない。実行は backend ディレクトリで `node --import tsx src/scripts/research/lifeAxisPreview.ts <既存FBディレクトリ> <別の出力ディレクトリ>`。ビルド済みdistの配信機能としては実装していない。

入力は日本標準時の生年月日・時刻。場所や性別から補正しない。時刻不明は00:00〜23:59の1,440分をすべて走査し、異なる文章が出る場合は複数候補、一部でも計算できなければ表示保留とする。文章が同じでも節入り経過日数などの出所の変動は保持する。秒境界を含む連続時間の確定、出生時刻の確率推定は対象外。

既存FBは読み取り専用の比較資料。旧文への評価を新文の評価に移さず、文章選択にも渡さない。新しい鑑定へのFB入力機能はこのプレビューにはない。
