# 0. 基本原則

* 複数占術で同じテーマが出ている時は、そのテーマが現実化しやすい傾向がある。
* 1つの占術だけで強い配置がある時より、西洋占星術・インド占星術・四柱推命・紫微斗数など、異なる系統で同じ領域が活性化している時の方が出来事が大きくなりやすい傾向がある。
* 同一系統内で複数のサインが出ていても、別占術からの一致ほど強く加点しない。
* 四柱推命、算命学、天中殺、納音は同じ干支データを利用するため、別々の独立票として扱わない。
* 西洋占星術とインド占星術は同じ天体を利用するため、完全な独立票として扱わず、一致時は中程度の加点にする。
* 出来事が起きる時は、「その領域が活性化する要素」と「その領域を固定・破壊する要素」が重なる傾向がある。
* 「恋愛運が高い」だけでは、交際・結婚・別離・不倫・片思いを区別できないため、Activation / Binding / Disruption / Secrecy を分けて判定する。
* 強い運勢は必ずしも良い出来事を意味せず、その領域の出来事が大きくなる傾向を示す。
* 凶作用だけが出ている時より、吉作用と凶作用が同時に強い時の方が、人生を変えるほど大きな出来事になりやすい傾向がある。
* 大運・マハーダシャー・外惑星などの長期周期が切り替わる時は、単発イベントではなく「人生の章そのもの」が切り替わりやすい傾向がある。
* 長期周期の切り替わりと、流年・流月・トランジットなど短期トリガーが重なった時は、実際の出来事として顕在化しやすい傾向がある。

> **位置づけ** 全項目に適用される上位制約。個別ルールではない。
> **独立性の定義**
> ```ts
> lineage: 'bazi'    // 四柱推命・算命学・天中殺・納音 → すべて canonicalSourceId を共有
> lineage: 'western' // 西洋占星術
> lineage: 'vedic'   // インド占星術（western と同一天体。一致時は中程度加点）
> lineage: 'ziwei'   // 紫微斗数（旧暦日付・出生時刻・年干の3由来を保持）
> lineage: 'supplemental' // 宿曜・九星
> ```
> **実装** `factsV2.ts` の `canonicalSourceId` / `derivations`、`findingsV2.ts` の `consolidateVotes` がこの原則の実装。**ただし本番未接続**
> **状態** シャドー実装済み・本番未接続

* インド占星術で5室支配星と7室支配星のテーマが同時に活性化する時は、恋愛が正式な交際へ発展しやすい傾向がある。
* 西洋占星術で木星が金星、月、7室支配星、DESCへ調和角を作る時は、出会い・交際・親密さが広がりやすい傾向がある。

* 紫微斗数で夫妻宮・子女宮・遷移宮が同時に活性化する時は、外出先や新環境を通じた恋愛が始まりやすい傾向がある。

> **占術** 四柱推命 / インド占星術 / 西洋占星術 / 紫微斗数（4系統すべて）
> **時刻** 四柱の日支・インドのダシャー・西洋の木星トランジットは時刻不要。ASC/DESC・紫微斗数は必須

# 2. 恋愛の「強い出会い」

* 長期運の切り替わり直後に7室・夫妻宮・日支が活性化する時は、その後数年間影響を与える重要人物と出会いやすい傾向がある。
* 大運切替と恋愛宮活性化が重なる時は、「ただの出会い」ではなく人生ルートを変える相手と出会いやすい傾向がある。
* インド占星術でマハーダシャーが切り替わった直後に5室または7室関連アンタルダシャーが来る時は、新しい恋愛フェーズへ入りやすい傾向がある。
* 西洋占星術で天王星がASC・DESC・金星・火星へ強く接触する時は、今までとは違うタイプの人と突然出会いやすい傾向がある。
* 西洋占星術で冥王星がASC・DESC・金星へ接触する時は、本人の価値観を根本から変えるほど強く惹かれる関係になりやすい傾向がある。
* ケートゥや海王星が恋愛領域に強く関与する出会いは、現実的な安定より「なぜか惹かれる」「忘れられない」「特殊な人」という形になりやすい傾向がある。
* 天王星とケートゥが同時に恋愛領域を刺激する時は、既存の恋愛観に当てはまらない相手へ強く惹かれやすい傾向がある。
* 恋愛Activationが高い一方でBindingが低い時は、強烈に惹かれても交際・結婚として安定しにくい傾向がある。

> **占術** 四柱推命（大運切替）/ インド占星術（マハーダシャー切替・ケートゥ）/ 西洋占星術（天王星・冥王星・海王星）
> **時刻** ASC/DESC 使用時は必須｜**系統** bazi + vedic + western
> **スコア** `relationship_activation` `relationship_binding` `identity_reset`
> **用途** 時期鑑定（「人生ルートを変える出会い」の年）
> **独立性** 天王星・冥王星・海王星は**世代天体**。ASC/DESC/金星への接触がある時のみ個人要因として扱う（§45）
> **状態** 未実装。外惑星のトランジット計算が `astrology.ts` に存在しない（木星・土星のみ）

# 47. 時刻境界の出生データ

* 出生時刻が時辰境界・ASC境界付近の場合、標準時方式と真太陽時方式の両方を計算する。
* 2方式で共通して出るテーマは高信頼とする。
* 一方の方式だけで成立する要素は低ウェイトにする。
* 紫微斗数の命宮や四柱の時柱が時刻補正で変わる場合、その要素単独で強い断定をしない。

> **位置づけ** データ品質の制約ルール
> **実装形** 同一入力に対して2通りの計算を行い、共通部分と差分部分で `confidence` を分ける
> **用途** 全ルール
> **状態** **未実装。**`toChineseStandardTime()` は存在するが、2方式の並行計算は行っていない。
> 実装すると計算コストが2倍になるため、**境界±30分のケースのみ適用する条件付き実装を推奨**

# 48. アプリの説明文生成原則

* 「○年に別れます」ではなく「関係の形を見直す出来事が起こりやすい時期」と表現する。
* 「浮気されます」ではなく「相手の事情や、これまで見えていなかった情報が表面化しやすい時期」と表現する。
* 「結婚します」ではなく「関係を正式な形にする流れが強まる時期」と表現する。
* 「転職します」ではなく「今の仕事や所属を変える選択肢が現実味を帯びやすい時期」と表現する。
* 「凶」ではなく「変化・負荷・再構築」のどれが強いかを説明する。
* 同じ配置でも結婚と離婚の両方があり得る場合、「関係が現状維持できなくなる」ことを一次判定とする。
* 出来事そのものより、「どの領域が動くか」「結ぶ力と壊す力のどちらが強いか」を出力する。

> **位置づけ** 文章生成の言い換え規則。**7件すべてが具体的な対応表として使える**
> **実装形** 禁止語リスト + 言い換え表として `narrativeValidator` に実装できる
> **用途** 時期鑑定の全出力
> **状態** **部分実装。**`timingCards.ts` の `titleFor()` / `caution` は本原則に準拠した文体になっている。
> ただし禁止語チェックの機構がないため、**ブロックを増やした時に守られる保証がない**

# 51. 複数占術一致ボーナス

* 1系統一致：ボーナスなし。
* 2系統一致：小ボーナス。
* 3系統一致：中ボーナス。
* 4系統一致：大ボーナス。
* 西洋占星術とインド占星術のみの一致は、同一天体由来のため通常の2系統一致よりボーナスを弱くする。
* 四柱推命＋算命学＋天中殺の一致は1系統として扱う。
* 「恋愛」という大分類だけの一致より、「秘密の露見」「固定化」「移動を伴う恋愛」など細分類まで一致した場合の方がボーナスを高くする。

> **位置づけ** 合議ボーナスの定義
> **実装形**
> ```ts
> function consensusBonus(lineages: FactLineage[], granularity: 'domain' | 'subtype'): number {
>   const unique = new Set(lineages)
>   const astroOnly = unique.size === 2 && unique.has('western') && unique.has('vedic')
>   const base = [0, 0, 0.10, 0.20, 0.35][Math.min(unique.size, 4)]
>   return (astroOnly ? base * 0.5 : base) * (granularity === 'subtype' ? 1.3 : 1.0)
> }
> ```
> （係数は初期値であり、100件・1,000件の分布検証で調整する）
> **独立性** 5〜6行目が§0の再掲
> **状態** 未実装。**最終行の「細分類一致」が、現行の `ConsensusKey` 12種では表現できない。**
> §49の18スコアを実装しないと細分類判定ができない

# 53. 最重要ルール

最終的な出来事予測は、

**長期周期 × 年周期 × 月周期 × 領域 × 方向性 × 複数占術一致**

で決める。

具体的には、

1. 大運・マハーダシャー・外惑星で「人生の章」を判定する。
2. 流年・トランジット・流年命宮で「その年に動く領域」を判定する。
3. 流月・プラティアンタルダシャー・短期トランジットで「発火する月」を判定する。
4. Activationで出来事が起きる可能性を判定する。
5. Bindingで結合・固定方向を判定する。
6. Disruptionで破壊・変更方向を判定する。
7. Secrecyで秘密・曖昧さを判定する。
8. Home / Career / Marriageなど隣接領域との組み合わせから具体的なシナリオ候補を作る。
9. 3系統以上で同じシナリオが出た場合のみ強い鑑定文にする。
10. 単一配置から「結婚」「不倫」「妊娠」「離婚」など具体事象を断定しない。

> **位置づけ** **実装順序の指定**。この10ステップがそのまま時期スコアの計算順序になる
